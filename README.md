# Caietul de Împăduriri

Laborator virtual pentru disciplina Împăduriri I (Universitatea din Oradea, Silvicultură, anul III, semestrul 5).

Deschide [index.html](https://rubenbudau2014-gif.github.io/caietul-de-impaduriri/) direct în browser. Nu este nevoie de cont.

- Lucrările de laborator se pot salva ca PDF din butonul „Salvează lucrarea ca PDF”.
- Rezultatele testelor se pot salva ca PDF după verificare.

Conținutul este protejat prin drepturi de autor; fotografiile din fișele de specii sunt sub licențele Creative Commons ale autorilor lor, indicate sub fiecare imagine.
